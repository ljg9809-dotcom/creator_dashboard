# Social Pulse · Creator Dashboard

Instagram, YouTube, Facebook, X의 성과와 콘텐츠 인사이트를 비교하는 한국어 SNS KPI 대시보드입니다.

현재 버전: **v1.1.0** · HTML, CSS, JavaScript로 제작했으며 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 실행

Node.js 18 이상에서 저장소 폴더를 연 다음 실행합니다.

```bash
npm start
```

브라우저에서 <http://127.0.0.1:4173>에 접속하세요. `PORT` 환경 변수로 포트를 변경할 수 있습니다.

루트의 `index.html`, `updates.html`, `app.js`, `styles.css`, `assets/`를 정적 호스팅 서비스에 그대로 배포할 수도 있습니다.

## 기능

- 주간 조회수 목표 입력 및 달성률 표시: 월요일~일요일 기준, 초기 목표 10,000회.
- 최근 최대 4개 완료 주간 평균 조회수 × 110%를 100회 단위로 올림한 추천 목표.
- 1일, 7일, 30일, 전체 기간별 채널 성과 및 조회수 추이.
- 팔로워/구독자, 유효 게시 수, 조회수, 전환수, 댓글 수 비교.
- 콘텐츠 썸네일, 검색, 채널 필터, 지표별 정렬, 페이지 이동, 큰 이미지와 상세 반응 보기.
- 채널, 콘텐츠, 일별, 원본, 주간 목표, 목표 변경 기록을 UTF-8 CSV로 다운로드.
- 실제 일별 데이터를 CSV로 가져오기.
- `updates.html`에서 기능 업데이트와 브라우저별 KPI 목표 변경 기록 확인.

## 데이터와 집계 기준

처음 접속하면 **2026-10-23 기준의 60일 샘플 데이터**를 표시합니다. 샘플 주간 조회수는 8,640회, 초기 목표 대비 86.4%입니다. 실제 SNS 계정에 연결된 수치가 아닙니다.

- 주간 KPI는 선택한 주의 월요일~일요일로 집계하며, 하단 기간 필터와 독립적입니다.
- 하단 필터는 데이터의 마지막 날짜를 기준으로 계산합니다.
- 조회수와 사용자 반응은 일별 증가량을 합산합니다.
- 동일 `date + channel + post_id` 중복 행은 마지막 행을 사용합니다.
- 유효 게시 수는 선택 기간에 업로드된 게시물을 채널과 게시물 ID 기준으로 중복 제거합니다.
- 전환수는 **좋아요 + 저장 + 공유 + 리포스트**의 합계입니다. 구매 전환을 의미하지 않으며, 댓글은 별도로 집계합니다.
- 반응률은 `(전환수 + 댓글) / 조회수 × 100`입니다.
- 팔로워/구독자는 기간 내 최근 스냅샷입니다. 채널 간 동일 사용자는 중복될 수 있습니다.

## CSV 가져오기와 썸네일

대시보드의 **CSV 다운로드 → 전체 일별 원본**을 내려받아 같은 형식으로 실제 데이터를 입력하세요.

필수 열:

```csv
date,channel,post_id,title,published_at,type,views,likes,saves,shares,reposts,comments,followers
```

- `channel`: `Instagram`, `YouTube`, `Facebook`, `X` 중 하나.
- `date`, `published_at`: `YYYY-MM-DD` 형식.
- 수치 열: 0 이상의 정수. 팔로워는 당일 총수이며 나머지 성과는 그날의 증가량입니다.
- 선택 열 `thumbnail_url`: HTTPS 이미지 주소. 다운로드한 샘플 CSV의 `assets/thumbnails/...` 경로도 다시 가져올 수 있습니다.
- 기존 CSV에는 `thumbnail_url` 열이 없어도 됩니다. 이미지 미등록/로딩 실패 시 안내를 표시합니다.
- 파일은 UTF-8 인코딩, 최대 10MB입니다. 가져오면 현재 데이터 전체를 교체합니다.

샘플 썸네일은 이 프로젝트에 포함된 부산기 카드뉴스 에셋입니다. 실제 게시물의 썸네일은 CSV에서 직접 지정할 수 있습니다.

## 저장 및 월요일 알림

데이터, 목표와 변경 이력은 현재 브라우저의 `localStorage`에 저장됩니다. 서버, 다른 브라우저 또는 다른 기기로 자동 동기화되지 않습니다. 필요한 데이터는 CSV로 백업하세요.

매주 월요일 09:00 (Asia/Seoul) KPI 입력 알림은 제작 시 Codex 채팅의 별도 자동화로 설정했습니다. **이 저장소에는 알림 서버나 스케줄러가 포함되지 않습니다.** 다른 곳에 배포하거나 복제해도 해당 알림이 생성되지 않습니다. 실제 성과 기반으로 알림에서 목표를 추천받으려면 해당 채팅에 CSV를 제공해야 합니다.

## 검증

```bash
npm run check
npm test
```

집계 검증은 중복 제거, 주간 목표, 네 가지 기간별 채널/콘텐츠 합계, 업로드 수, 추천 목표 및 CSV 처리를 확인합니다.

## 파일 구성

```text
index.html                 # 대시보드
updates.html               # 업데이트 기록 페이지
app.js                     # 샘플 데이터, 집계, 화면과 CSV 처리
styles.css                 # 반응형 스타일
assets/thumbnails/         # 샘플 콘텐츠 썸네일
scripts/serve.cjs           # 로컬 정적 서버
scripts/check.cjs           # 집계 및 CSV 검증
```

글꼴은 Google Fonts의 DM Sans와 Noto Sans KR을 사용하며, 연결이 안 되면 시스템 글꼴로 표시됩니다.
